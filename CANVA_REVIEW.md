# Visual review

## Canva import

[PVM Learning Lab — Visual Review](https://www.canva.com/d/6IPkLU4fYNawy32) was created from the public site for review. Canva exposed an empty page and no readable text content, so the imported design could not support a reliable element-level critique. The read-only review transaction was cancelled without changes.

## Browser visual review

I reviewed the actual app in Edge at desktop, tablet, and mobile sizes. The screenshots in [QA_REPORT.md](QA_REPORT.md) show the relevant pages.

- Stage navigation and the stage title make the learning sequence and current task easy to locate.
- The waterfall keeps exact period totals beside a zero-start impact scale, while the interpretation cards explain the assumptions and business meaning.
- Mobile stacks the chart, simulation controls, explanations, and reconciliation without horizontal overflow.
- In the full five-factor bridge, a connector could wrap onto the preceding line by itself. Each arrow or plus sign now stays with the value card it introduces, preserving the reading order at narrow widths.

The browser review found no other high-value visual changes. The empty Canva import supplied no additional feedback to apply.
