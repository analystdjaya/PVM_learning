# Figma design review

## File

[PVM Learning Lab in Figma](https://www.figma.com/design/1NY05JxCMhSvaeRCOwb2kL)

## Foundations applied to the HTML

The file contains a PVM foundations specimen with local primitive, semantic color, layout, and typography variable collections; Inter text styles; a quiet panel effect; semantic positive, negative, attention, information, and focus states; and signed impact examples. The specimen's title and chart note were resized after its first render exposed clipping.

The HTML follows the resulting direction: warm canvas and white surfaces, dark ink, an Inter-first local font stack, restrained semantic colors, strong labels, and signed chart bars that communicate direction through position and signs as well as color.

## Free-plan boundary

The connected Figma Starter workspace enforced its MCP tool-call limit while creating the page skeleton. The foundation file and specimen were saved, but the planned reusable component sheet and Orientation, Revenue, Gross Profit, and Interpretation Lab compositions could not be completed in this run. No paid feature was enabled.
